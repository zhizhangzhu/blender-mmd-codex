# 低流量、可核验的MMD持续学习

2026-11-13，按猪猪的实际反馈制定。观海子是首要质量参考，Gosari542保留，御手洗板蓝根作为原神动画渲染的补充参考。学习的产物应是能改善人物／空间质量的知识与验证方案，不是更多网页、插件或重复摘要。

猪猪补充：持续学习主要是实际阅读外部MMD教程、图文和技术讲解。每轮把时间优先用在外部正文、关键图示与技术理解；队列／笔记作为收尾，不能把开发管理工具当作本轮学习成果。最近实读示例见[Nilo、Ray-MMD与Filament](EXTERNAL_MMD_TECHNIQUES_2026_11_13.md)。既有[队列](../catalog/learning_queue.json)可用于去重和续接。

## 先读文字，打开视频先停止播放

先检查已有来源账本、本地笔记与缓存，避免同一资料反复下载、转写和送入上下文。优先原作者图文／源码，其次视频简介、置顶说明与字幕；只有需要核实节点接线、参数或视觉效果时，才看对应画面。

打开研究视频后先检查实际 `video.paused`。若仍在播放，通过当前页面可见的播放／暂停控件停止，再读取状态确认 `paused=true`；不能以点击请求已发出当作暂停完成。先暂停，再做可能耗时的检索、代理委派或文档写作。需要查看画面时选较低清晰度，短暂播放目标时间段，结束后再次确认暂停。字幕抓取不需要持续播放4K视频。

不要让研究视频自动连播到无关作品。结束时释放或关闭由代理创建的临时研究标签；不要关闭用户原有工作标签。若控制链异常而无法确认暂停，明确记录失败，不能保持播放同时反复初始化。已知属于代理自己的临时标签可按正式浏览器清理接口关闭，以停止继续消耗流量。

本轮实际发生了自动连播；随后已关闭两个由主线程创建的Chrome研究标签，并用标签列表确认它们不存在。没有把这个结果写成“全部播放器已暂停”或“已修改全局自动播放设置”。

## 字幕一次获取，后续按时间码读

在已授权页面确认视频、分P与字幕轨，再优先使用页面文稿／字幕列表；必要时检查该页自身加载的 Network 响应。只取目标字幕正文，避免下载完整视频、导出整个HAR或将所有网络请求重复打印到上下文。URL轨道清单与完整正文必须分开验收。

采集到合法的正文后，使用[离线整理器](BILIBILI_SUBTITLE_WORKFLOW.md)输出标准JSON、SRT与带时间码阅读稿。CLI只返回条数、时间覆盖和SHA；后续按问题读取相关片段，不重复加载整份转写。完整第三方字幕保存在私人研究目录，repo只保存原创归纳、来源和核对范围。

自动识别可能把材质、法线、节点名称识错。字幕用于定位，节点端口、数值、坐标方向和最终画面仍须交叉核实。没有取得正文或没有核对首末、中间范围时，不称“全文学习完成”。本轮尚未取得可验证的B站完整字幕文件。

## 每轮只解决明确缺口

每个学习单元只回答一个可见质量问题：来源→新增结论→当前工程对应点→一个可关闭实验→拒绝条件。若只是复述已知知识，不登记为新能力。先证明新假设在同帧消融与短连续测试中有收益，再把它提炼成参数预设。

并行子智能体按互不重叠的主题分配：脸影设计；头发与材质响应；作者参考与来源核对。主线程统一输入版本、术语和证据状态。子任务不会独立改同一个生产工程或把研究结论晋升为已实装；最终整合、验收与状态更新由主线程完成。

## 浏览器故障要有重试边界

区分安装／授权、进程运行、浏览器发现、页面正文、网络字幕、画面核对，逐级记录。空标签、一次超时或调试连接异常不能直接归因为用户缺权限；浏览器编号在重新初始化后可能变化，不能硬编码旧编号。

复用成功绑定，优先正式API与小范围正文读取，不反复输出完整首页、推荐列表和全部网络日志。一次有根据的恢复后，同一阶段再次失败就记录具体错误并换用已有图文或本地资料；下一轮须有新证据再恢复该分支。网络诊断打印前先按目标域名／路径筛选并移除不必要查询参数，避免混入上报日志。

本轮Chrome安装、扩展启用和native host均已由官方只读脚本确认；实际成功读取过教程正文，随后仍遇到 `Debugger unattached`。这是连接边界，不能继续建议用户补安装权限。详情见[浏览器证据](BROWSER_AUTONOMY.md)。
