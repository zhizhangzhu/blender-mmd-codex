# 对照观海子：清晰的脸部描边与五官内线

2026-11-09，猪猪指出上一轮脸部暖色细线不足，希望像观海子的视频一样有清晰黑线。本轮重新审看用户提供的本地原分辨率参考，并在既有银发、金属与衣料精修工程上独立升级脸线。交付目录为 `D:\codex\output\MMD-Face-Ink-Refinement-v1`；旧 `outlines-v1.json` 和六套风格 v1 均保留。

## 参考中实际看到了什么

本轮查看此前解码的 Cherry 17.650 / 24.083 秒原帧，以及《亲亲小狐狸》85.466 / 106.183 秒原帧，另做原像素裁切审看。证据是选定帧和局部，不声称完整逐镜头看完两支视频。来源与作者/后期署名见 [观海子参考记录](GUANHAIZI_REFERENCE.md)。

| 部位 | 可见表现 | 对本工程的修改 |
| --- | --- | --- |
| 脸颊、下颌 | 有连续可辨认的深色轮廓；Cherry 带红棕色，Fox 侧脸有深色细边，亮边也会随光照出现 | 不再以“脸应该柔和”为理由保留几乎看不见的线；给脸单独提高覆盖与深度 |
| 鼻口 | Cherry 鼻部有短笔画，嘴角/闭口线明确；Fox 侧面鼻尖与嘴的形状清楚 | 本模型已有鼻部几何轮廓，增强侧面鼻线；嘴缝按原 UV 和贴图局部单独加深 |
| 眉眼 | 深紫/深棕等明确的图形内线，与皮肤有足够对比 | 保留眉睫形状与透明边，单独降低其颜色增益，不给虹膜加黑遮罩 |
| 角色外框 | Cherry 有白色贴纸外沿，内部仍有深色细线 | 白外框与脸内线是两层设计，不能用白色外框代替脸部细节 |

“黑线清晰”是本轮目标；不把参考所有像素误记为纯 RGB 黑色，也不因此否定猪猪对脸部可读性的判断。没有恢复作者的着色器、法线、原 MME 参数或源工程。

`review/reference-faces.png` 对照三个参考局部，单独裁切保留原像素；拼版只等比缩放，没有给参考加锐化、重新调色或描线。`review/visual-evidence.json` 记录来源和裁切坐标。

## 三种线条分别处理

新预设 `presets/quality/outlines-v2-face-black.json` 继承身体、头发和毛领的既有分区，通过 `material_overrides` 单独控制 `颜`，避免把脸线需求扩展成舌头、口腔和双手统一加粗。

- **脸部外轮廓**：MMD Tools 原反向外壳；`颜` 边色参数 `[0.003, 0.002, 0.003]`、不透明度 1、原 PMX/顶点宽度系数 1.75。旧版分别为 `[0.08, 0.04, 0.045]`、0.70、0.70。另渲染 2.5 粗线方案作对照，当前选 1.75。
- **眉睫内线**：只处理已有 `眉` / `睫` 的 NPR 最终颜色，增益 0.50；保留原贴图、形状和 Alpha。没有用粗黑外壳替代五官绘线。
- **嘴缝**：核对 `NPC_Female_Face010_01_Aksinya01_Tex_Diffuse.png`，在已审看的嘴缝 UV 小区域内，用原贴图线性 R-G 差筛选红色线，再混入受控深色。原贴图和皮肤明暗链保持，UV 随原表情变形，不在皮肤上直接覆盖整块黑色。

MMD Tools 原边材质含内部 Gamma 节点，上述颜色是写入节点的参数，不应宣称它与最终显示 RGB 或其他着色器的线性色值完全等价。实际边线深度用渲染对照判断。

本轮没有凭空给正面鼻子画固定黑竖线：正面原本仍有鼻部亮形，侧面鼻部几何轮廓会形成深线。若后续要模仿 Cherry 的正面鼻短笔画，应另做随视角和表情验证的设计，不能把侧面轮廓增强说成所有鼻内线都已复制。

嘴缝 UV、色差阈值和材质名称是阿克西妮娅专属设置。脚本会检查原面部图像身份，换角色直接套用会报错，需要重新审查。没有修改源素材、UV、骨骼动作、表情数据或实时物理；使用既有烘焙衣发动作。

## 实际验证

`stills-v2` 保留原版、仅加深五官而关闭脸外壳、选定黑线、较粗黑线四种状态，各渲染 661 / 781 / 900 三帧，720×1280 / 64 samples。`review/face-comparison.png` 使用同一姿态、相机、灯光，裁切等比缩放；不是重新摆头或改变曝光后比较。

几何位置与三个姿态的全部骨骼矩阵哈希保持一致；重复应用预设不增加节点，也不重复叠乘顶点宽度。`mmd_face_ink.py` 保留其原输入以使重复应用幂等。

脸外壳关闭/开启的真实渲染差异超过 5 个显示色阶的像素数分别为 379 / 671 / 296，其中有接近黑色的输出像素。它们证明脸外壳实际产生了线条，**不是统一线宽、风格相似度分数或所有描边像素的统计**。差异也包含反锯齿/边缘采样。

本次单独选择 `mmd_edge.颜` 的 Cryptomatte 输出全零，没有拿到有效隔离信号；原因未确定，不用它作为通过凭据，也不把零遮罩解释成画面没有脸线。改用只关闭脸外壳、保持五官处理一致的渲染差分验证。既有角色/脸部合成遮罩本身有非零信号，仍由后期做字幕前后层控制。

八秒动态使用源帧 421–900、60 fps、720×1280 / 64 samples，沿用八秒镜头、既有衣发烘焙、高光方向动画和官方 Tall 动态文字。伴奏沿用此前来源与偏移，手动卡点仍由用户处理。实际最终视频、解码结果及校验值以交付 `delivery-manifest.json` 为准；这是八秒脸线升级片段，不冒称二十秒全高清旧成片已同步替换，也不把竖屏检查算作横屏已检查。

## 复现入口

```powershell
# 同姿态四组对照。不要使用已有输出目录。
& 'E:\tools\Blender Foundation\Blender 5.2\blender.exe' --background '<审看过的精修副本.blend>' `
  --disable-autoexec --python-exit-code 1 --python scripts/review_face_ink.py -- `
  --preset presets/quality/outlines-v2-face-black.json --output-dir 'D:\codex\output\face-ink-new'

# 既有八秒镜头工程上重渲：参数最后应用，避免被风格材质重设覆盖。
& 'E:\tools\Blender Foundation\Blender 5.2\blender.exe' --background '<八秒精修副本.blend>' `
  --disable-autoexec --python-exit-code 1 --python scripts/mmd_caption_render.py -- `
  --output-dir 'D:\codex\output\face-motion-new' --cache-dir 'D:\codex\temp\face-motion-new' `
  --aspect portrait --start 421 --end 900 --width 720 --height 1280 --percentage 100 --samples 64 `
  --outline-preset presets/quality/outlines-v2-face-black.json
```

横屏复用材质方法时，先用横屏专属相机在最终分辨率下审看脸占比、线宽和遮挡，再保存对应风格/画幅新版本。参数共享不代表两种画幅拥有相同像素线宽。
