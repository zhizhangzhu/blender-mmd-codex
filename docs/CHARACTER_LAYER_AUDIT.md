## 已发现并修复的问题

旧空的部分解析式受光使用固定向量 `(-0.55, -0.68, 0.49)`；旧方向修复器只识别另一组精确常数，因此不能据“存在方向驱动器”推断全部色带、高光都会随灯变化。旧主颜色还经过材质色带、局部 AO、额外真实受光与 AO 等多次处理。单独抬亮最终输出会保留这些职责重叠。

本轮准备脚本把新主 Emission 的颜色接到独立、可检查的受光链。旧节点留在文件中用于历史依赖、专有遮罩或其他分支；是否失效必须看新输出的上游可达性，不能只数文件中存在多少旧节点。

独立代码审计发现 v1 查找 `Face ink | mouth crease`，而阿克西妮娅现有节点实际名为 `Face ink | Mouth crease`。大小写不匹配会漏接专门的嘴缝修饰。准备脚本已修正并重建 production-v2；新版验收包含嘴缝节点到主颜色的可达性。production-v1 不作为最终交付工程。

## 新版节点职责

主要人物面材质沿以下方向输出：

```text
mmd_shader.Color
  → Character layers | source color and chroma
  → 原模型专用嘴缝修饰（存在时保留）
  → Character layers | base times one palette
  → Character layers | one contact application
  → Character layers | one directional hair highlight（适用的头发材质）
  → 现有主 Emission.Color
  → 原有 PBR / 透明末端
```

`mmd_shader.Color` 保留 PMX 的贴图与球面等组合语义，不把它称为已经拆净的游戏原始 Albedo。验收比较其输入连接和内部组合节点组，避免借重建受光之名丢掉原材质信息。Alpha 继续来自 `mmd_shader.Alpha`，保留透明消费者和末端 Shader 结构。

综合受光由白色 Diffuse → Shader to RGB → 灰度 → 固定标定范围生成。它包含灯组、法线、衰减、遮挡及间接受光，不是单独的投影通道。脸部探针法线来自随头部变化的前向辅助对象，身体使用自身法线。适用的脸部 SDF 在进入唯一材质色带之前，与真实受光合并；不在色带之后再乘第二次 SDF 暗色。

唯一材质色带之后只应用一次短距离接触 AO。发丝高光使用随头部变化的方向、实际主光方向和观察方向；适用时保留模型已有的发丝遮罩。旧固定方向、旧色带、旧 AO 和旧 MatCap 叠加不再进入这条主颜色路径。

眼睛、眉睫等专有特征保留原设计分支。金属及其他已存在的 PBR 闭合保留；其实际受光仍由 PBR 决定，不能宣称所有闭合已经变成同一条 NPR 色带。金属遮罩、透明与角膜是需保留的不同职责。

## 当前参数与灯光边界

参数源：`presets/quality/duet-character-layers-v1.json`。固定受光标定范围为 0.025–0.24；常规短距离 AO 为 0.035、强度 0.10，脸部为 0.018、强度 0.045。这里的距离是本工程尺寸下的 Blender 单位，不能直接推广到不同缩放模型。

每位人物的主光、补光、轮廓光起点分别为 450 W / 0.85、18 W / 3.0、95 W / 1.6。色带按皮肤、银发、金发、布料、皮革、毛领及金属等分别配置；这组功率与固定标定范围是一组工程标定，不应拆开当通用预设。

舞台灯和强投影灯限制到舞台接收集合；人物参考灯限制到各自人物接收集合。验收检查启用灯的接收对象和人物灯预算，避免舞台投影灯意外把人物色带抬满。灯光链接是美术控制，其存在不等同完整物理照明。

## 已验证范围

原生机器验收检查了保留的 MMD 组合、贴图输入、Alpha 消费连接、末端 Shader 闭合、PBR 底色与 Alpha、嘴缝可达性、SDF 输入、主颜色单次色带 / AO / 发丝高光职责，以及灯光链接。源工程的 95 张文件图像保持打包，颜色管理、渲染约定和动作相机抽样对比通过，继承的 File Output 静音。

动作相机采样帧为 1、2100、4140、4200、4250、4290、4439、8400、11899，比较两个人物的骨骼矩阵、相机矩阵与焦距。它能发现这些时点的差异，不等同逐关键帧全量动作数据证明。

转头、移灯、绕拍各 24 帧，共 72 帧，使用无后期、无雾、无景深及无运动模糊的中性诊断条件。主线程已完成全部解码和辅助轴误差检查，并查看每个案例的 0、4、9、14、19、23 帧双角色脸部条图，未报告明显异常。这里的视觉结论属于这些抽样范围；不能把全解码写成已逐帧人工观看，也不能由短测试保证整曲所有姿态都稳定。

## 仍需提升与单独验收

1. 在最终婚礼灯光、体积、Glow、字幕和色彩输出重新合成后，检查同帧对照与连续五秒成片；中性测试通过不能替代最终场景审片。
2. 分角色精修脸部 SDF 过渡、鼻嘴与眼周层次、发丝高光形状，检查侧脸和遮挡；避免只靠压暗面部增加立体感。
3. 核对金属遮罩边界、粗糙度与 PBR 反射，区分布料、皮革、金属和毛领；同时检查 NPR 与 PBR 分支在移灯时是否协调。
4. 黑线仍需在交付分辨率、不同镜头距离及运动状态下检查分区粗细，不能把相对加粗称为固定像素线宽。
5. 本审计没有新增或认证胸部、衣物、头发物理；这些需要原生约束、连续模拟、烘焙与独立重开验证。材质三轴测试不构成物理验收。
