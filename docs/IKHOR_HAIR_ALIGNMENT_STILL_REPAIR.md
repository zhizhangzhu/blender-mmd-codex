# 伊科尔头发错位：静帧修复

2026-11-17，猪猪指出刘海和左侧分叉持续错位，并给出正确发型参考。本轮明确只看静帧，不生产新视频。

源工程为MMD-Jelly-Eyes-v1/production-v16。实际检查发现直接挂在头骨下的多个Bone_Hair骨骼带有约28–53mm额外平移，改变了发根相对头骨的位置。位置数据来自此前物理视觉烘焙，并非最近高光、泛光节点移动了网格。具体物理导出为何产生这些偏移尚未完整追溯，不能声称已修复底层物理求解器。

controls-v3分别实际渲染原状、仅清零头发位移、清零位移和旋转三个静帧。只清位移仍有侧发外翻；恢复原模型头发绑定姿态后，侧发收回、错误前移的刘海归位。选择第三种作为本轮静帧候选，保留原模型顶点与权重，不雕刻或移动整顶头发去猜位置。修改的是独立复制的伊科尔Action中Bone_Hair曲线；原Action保留，非头发曲线哈希保持一致。

当前输出为 `D:/codex/output/MMD-Ikhor-Hair-Alignment-v1/production-v1/Ikhor_Hair_Aligned_Still.blend`。当前4290帧的伊科尔面部刘海阴影按修正后几何重算并内嵌，不能继续使用旧错位头发的阴影遮罩。独立重开核对发根零偏移，再输出原镜头、完整头部正面和四分之三静帧。

这是**恢复原发型并随头骨绑定的静帧修复候选**：头发额外物理旋转／位移被隔离，未新烘焙头发动态，也未验证连续摆动。伊科尔本轮新增面部发影只对4290重新计算。后续若制作视频，须重新完成合理发根约束的头发物理和对应动态阴影；不直接把这份静帧工程当作完整动态修复。原五秒v16视频仍保留，但猪猪已指出其中头发错位，不能登记为美术通过。

入口：`inspect_ikhor_hair_alignment.py`只读审计；`repair_ikhor_hair_alignment.py`为三项隔离静帧；`save_ikhor_aligned_hair_still.py`固定源副本、修复曲线、重算法线受遮挡图、保存与重开并只渲静帧。没有新视频编码或全曲渲染。
