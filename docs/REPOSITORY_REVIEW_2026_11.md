## 建议的知识职责

目录可以保持稳定，按职责建立入口：

- **现行事实**：目标、用户最新反馈、当前工程／视频、已接受对照、未完成范围；由状态JSON与少量入口文档统一维护。
- **制作指导**：从素材审计到人物、物理、舞台、镜头、字幕、色彩和交付的有条件流程；每一步写输入、动作、产物、验收及失败回退。
- **技术指南**：人物NPR、物理运动、舞台／镜头／后期分别整理可执行方法；链接到原始实验，不复制所有参数造成两份真相。
- **实验记录**：原神Face Factor、鸣潮发丝、法线、描边、光束、AOV、色彩等原记录继续保留；清楚说明输入工程与验证范围。
- **来源台账**：原作者／官方／社区实现分别标识，记录文章正文、视频画面、字幕、OCR或本地节点到底读到了什么。
- **历史快照**：只承载当时状态与旧任务，不被制作代理当成下一步命令。
- **预设配方**：renderer、post、aspect/director、material adapter、physics和project各司其职；一个组合的组件均有证据，不表示该组合已通过。

现有知识应覆盖：人物与着色8篇、舞台灯光12篇、后期字幕4篇、动作成片7篇、参考审美4篇、工具环境2篇、署名素材2篇，以及维护3篇。具体文件映射在审计JSON中保留，新的指南应链接这些旧记录，而非重写后抹掉失败边界。

## 后续质量优先级

1. **P0 人物受光合同。** 先明确保色Emission、SDF形体明暗、真实几何遮挡、法线、高光、AO和描边各负责什么。用无后期中性近景确认肤色、额头／颈部、手臂、眼睛、发束层次；禁止用全图增亮、泛光或加灯数量掩盖接线问题。
2. **P0 动态验证。** 固定灯转头、固定头移灯、相机绕拍，追加双人遮挡、抬臂、闭眼／睁眼。五秒原舞蹈技术通过不能替代每个材质分支的受控测试；静帧与教程截图只能进入较低证据层。
3. **P1 材质／法线资产。** 头发亮带、金属／布料、眼睛与透明层逐角色适配；阿克西妮娅有自带FaceLightmap，空缺配套身体／头发游戏Lightmap，不能把颜色图或新制遮罩称为游戏原始控制图。
4. **P1 自然物理。** 复用已验证的衣发烘焙，换动作／缩放需重新模拟。胸部物理目前没有独立验证证据，列为新增实验，不把已有刚体或角色骨骼当作效果完成。
5. **P2 舞台、镜头与后期。** 人物基础通过后再做光区、局部雾、反射和体积感；景深、拖影、字幕与主题色服务具体镜头。横竖屏有独立构图和排版；当前资料不授权直接把双人横屏裁成竖屏。
6. **P2 全曲与交付。** 先稳定短样片及用户认可，再按镜头段落扩展；全曲、原声时间结构、物理、镜头校正与发布署名逐项检查，不能由局部成功推断整曲完成。

优先级是整理后的制作顺序，不宣称本轮新增指南就已实现以上全部能力，也不把游戏级质量简化为某个插件、一个Shader或一项分数。
