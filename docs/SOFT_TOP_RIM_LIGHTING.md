# 柔光、顶光与逆光：提亮礼堂而保留层次

后续猪猪提出增加婚礼蓝金、射灯／光束、光晕和主题色字幕，独立分支见 [蓝金婚礼学习与制作](BLUE_GOLD_WEDDING_STUDY.md)。本版柔光参数保留，新的射灯属于环境美术，不替代人物主光／补光／轮廓光的职责。

2026-11-12。猪猪指出上一版整体太暗，提出增加柔光、顶光或逆光，并继续参考观海子《亲亲小狐狸》。本轮沿用 [官方字幕与聚焦灯光](DUET_CAPTION_STABILITY_AND_LIGHTING.md) 的人物、PBR 礼堂和字幕分组，只重做同一段 4140–4439 的五秒 1080p60，不启动全曲。

## 参考与判断

重新查看本地《亲亲小狐狸》18.000 秒实际画面：头发、肩部与飘带有窄亮边，脸部清楚，背景仍比人物暗。借鉴其主体与背景的分离和受光方向，不从画面断言作者的具体灯型、数量或功率。参考来源、署名与完整观察边界见 [观海子参考](GUANHAIZI_REFERENCE.md) 和 [舞台再研究](FOX_STAGE_ART_DEEP_STUDY.md)。原视频投稿者为观海子，简介另有黑煤球后期署名。

上一版侧区压得过暗，地板与花卉的大面积细节不容易看清。直接加曝光会连人物、字幕和亮处一起抬高，因此这次通过真实大尺寸面光、环境间接光与材质反射率提亮场景，同时保留左右小范围冷暖重点。

## 最终参数

配置为 `presets/stages/hesperides-soft-top-rim-v1.json`。这些数值绑定本工程的空间尺度，不是作者原预设。

| 灯 | 位置 → 目标 | 功率／尺寸 | 职责 |
| --- | --- | --- | --- |
| 人物上方柔光 | (0,0.5,7) → (0,0.5,0) | 450 W／6 | 柔和顶光，照亮人物周围与走道上表面 |
| 礼堂顶部反弹光 | (0,12,12) → (0,25,3) | 3000 W／14 | 大面积弱冷色，提亮台阶、花卉和建筑 |
| 正前方柔和补光 | (0,−7,7) → (0,12,2) | 1300 W／12 | 减少前景大块死黑；仅照场景 |
| 左后方暖逆光 | (−3,3.5,5) → (0,0,1.3) | 700 W／3 | 人物反光与边缘分离，不额外染亮整片背景 |

环境 strength 从 0.18 提到 0.30，场景反射率乘色从 (0.85,0.88,0.94) 恢复到 (0.96,0.97,1.0)。不改变曝光，不把角色和文字统一提亮。之前的四盏局部冷暖灯继续保留。新面光不参与体积散射，避免用雾把画面重新变灰。

人物是 NPR，真实逆光不会自动完整改变 Emission 表面。因此保留实体灯带来的高光，同时调整既有方向性边缘模块：头发 gain 1.0、衣服 0.38，边缘幂从 5 改为 4，方向对应同一盏暖逆光。完整脸部、眉眼、嘴与线条排除；这部分是明确的美术补充，不冒充完整物理光照或作者原始 Shader。

首次候选的 700／4500／2200 W 三组补光和环境 0.36 令地面过亮，实际看过后降低到表中数值。`production-v1` 保留为中间实验，最终以 `production-v2` 为准。

## 实际工程与复用

输入：`D:\codex\output\MMD-Duet-Captions-Contrast-v1\production-v3\Franken_Duet_Focused_Caption_Source.blend`。

生成脚本 `scripts/prepare_soft_top_rim.py`：检查输入版本、防止重复叠加、静音全部旧 File Output、添加链接到实际接收对象的灯，调整反射率和边缘，人物隐藏后重新烘焙场景 GI。九时点比较全部骨骼／相机／焦距，保存打包工程。之后 `verify_caption_master.py --softlight-profile presets/stages/hesperides-soft-top-rim-v1.json` 独立重开检查。

交付根目录：`D:\codex\output\MMD-Duet-Soft-Top-Rim-v1`。

- 工程：`production-v2\Franken_Duet_Soft_Top_Rim.blend`。
- 无字幕视频：`lighting-sample-5s-v1\Aether_Duet_5s_REVIEW.mp4`。
- 官方字幕原声视频：`captions-5s-v1\Franken_Duet_5s_Captions_REVIEW.mp4`。

渲染仍保持原生 60 fps 和既有采样，字幕使用已修好边界的 `duet-official-locked-v2.json`，不挖开前景文字的脸部区域。指定原声 FLAC、音频起点 68.983333 秒、相机轨迹、焦距、景深和物理烘焙保持原配置。

## 验收与限制

原生控制图分别关闭新增三盏柔光的直接贡献，以及人物逆光／补充边缘，核对实际画面影响。柔光关闭图仍保留新 GI 和反射率，不称为“所有提亮手段都关闭”。使用同一 4250 帧的旧版与新版对照判断整体暗部变化，不能把开关像素差当作质量评分。

完成所选 300 帧后检查分辨率、原生帧数、时长、音轨、冻结及字幕前后层，目视检查代表帧和字幕边界；最终报告以交付目录 JSON 为准。技术通过不等于用户美术认可，柔光边缘、半透明材质与 NPR 补充亮边仍有自身限制。当前没有扩展全曲、竖屏或重做镜头。
