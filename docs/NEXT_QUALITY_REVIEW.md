# 下一轮质感学习与双人全曲优先级

本页针对2026-11-09八秒脸线版，作为历史诊断保留。2026-11-13最新Grounded五秒人物仍需提升，现行优先级见 [知识地图](KNOWLEDGE_INDEX.md)、[人物手册](CHARACTER_NPR_PLAYBOOK.md)和 `catalog/current_state.json`，不把下文旧范围当作当前制作状态。

2026-11-09，重新对照最新八秒脸线版、Gosari542 与观海子的选定参考帧，并检查现有实现。以下是美术诊断和待学习计划，不是新增效果已经验证的声明；没有完整连续观看参考的地方不声称做了逐镜头分析。

## 最值得提高的部分

| 优先级 | 当前可见或实现上的差距 | 下一步学习与试验 | 具体检查方式 |
| --- | --- | --- | --- |
| 先做 | 黑手套、部分毛领和脸部的形体较平；角色已有主光联动，但大部分 NPR/Emission 不会因此自动获得完整相互投影 | 学习如何将受控遮挡/投影输入现有 NPR，区分形体阴影、接触阴影和艺术 AO；对脸部单独限制，而非一并变黑 | 同姿态比较手指与掌面、下巴与领口、头发与脸、配饰与衣物的关系；转动人物和灯光复查 |
| 先做 | 明亮的脸很干净，但鼻颊层次有限，部分虹膜高光占比很大 | 学习定制面部阴影图（含 SDF 路线）、眼窝/睫毛层次与虹膜高光控制；与已试过的椭球法线比较，避免只为增加节点重复做法线 | 正面、三分之二侧面、侧面、闭眼/睁眼和移光对照；虹膜颜色、瞳孔、眼白仍可辨 |
| 随后 | 银发已有方向性高光，但部分亮带像贴在头上的白条，发束连续性和发根/后发分层仍可设计 | 学习逐发束方向/控制图、亮带宽度与破碎形状，区分贴图自带亮部和新高光；把金发与银发分别适配 | 固定光转头、固定头移光的连续片段，检查亮带游动、断裂和过曝 |
| 随后 | 蓝布料、金边、毛领已有区分，但部分材质的反光形状、软硬度和深度仍接近 | 学习粗糙度/高光遮罩和简洁反射环境，让金属有可读亮暗变化，布料保留宽而克制的响应，毛领用整体体积和边缘层次 | 同一近景看金属、布料、毛领与手套；小尺寸不糊，大尺寸不靠高频噪声假造细节 |
| 全曲必做 | 新精修只在八秒版验证；原二十秒正式片尚未统一升级。双人、全曲带来表情缺轨、物理与镜头的新范围 | 学习和完善角色分组、表情映射、接触修正、镜头段落设计、连续验收；保留现成作者镜头并做必要局部适配 | 开头/主歌/副歌/桥段/结尾都检查；近景服务表情，远景服务互动，横竖各自核对 |
| 后期完善 | 图形换底目前从带背景 beauty 按遮罩近似分离，复杂透明/景深边缘可能保留旧背景色 | 学习角色与舞台分层 RGBA、预乘 Alpha、独立线条/高光输出、16-bit/浮点中间格式以及清晰的显示变换顺序 | 换成白、黑、高饱和底色检查边缘；防止二次显示变换、黑边、白边、字幕保护范围误差 |

轮廓线应继续检查随景别变化的像素宽度、脸内外线的关系和时间稳定性；不把上一轮的“加深线色”当成线条系统的最终形态。

## 值得学的工具和原作者资料

- **Abnormal**：[作者 Wiki](https://bnpr.gitbook.io/abnormal-wiki)与[法线球形化教程](https://bnpr.gitbook.io/bnpr/shaders/toon-shading-nbpr-abnormal-normal-sphering)。本机此前仅临时注册测试通过，GUI 编辑流程尚未验证；下一次只有实际编辑、保存和渲染有效，才能记录为掌握。
- **现有 Paper Anime Render Helper**：先研究与现有 MMD Color/Alpha 链的衔接。此前已证实其高光函数对普通 Principled 测试材质与本项目 MMD 材质的返回不同，不能直接把全模型转换后宣称透明/球面语义不变。详见 [QUALITY_LIGHTING_LAB.md](QUALITY_LIGHTING_LAB.md)。
- **分区卡渲设计**：[Juan Salice 原作者 NPR Breakdown](https://juansalice.artstation.com/projects/LR5y6R)对头发高光、阴影、内线和轮廓的遮罩职责有明确拆解；参考设计方法，当前角色没有其原始 ILM。
- **Blender 原生渲染/合成**：[5.2 EEVEE 节点支持说明](https://docs.blender.org/manual/en/5.2/render/eevee/limitations/nodes_support.html)说明 Shader to RGB 可将 BSDF 灯光结果转为颜色，但带有材质方式的限制；[Shader to RGB 文档](https://docs.blender.org/manual/en/5.0/render/shader_nodes/color/shader_to_rgb.html)还列出 PBR/通道方面的限制。因此它是候选阴影输入路线，不是把现有所有问题一键解决的开关。[Alpha Convert 官方说明](https://docs.blender.org/manual/en/latest/compositing/types/color/alpha_convert.html)明确 Blender 渲染/合成的预乘 Alpha 语义，可用于完善分层合成。

Malt/Goo 等可在独立实验中研究，目前未证明迁移现有双人 MMD、Morph、描边和后期链的收益，不安排为全曲制作的默认前置依赖。插件选择按要解决的实际问题决定。

## 两类风格的判断标准

Gosari542 方向继续保持明亮脸部、清楚虹膜、材质分区和柔化舞台；观海子 graphic 方向侧重平面色块、清晰深线、图形/文字节奏，neon 方向侧重舞台与人物分离、受控彩光和光点。形体层次增强的程度应分别调整，不把“电影感”统一解释为深阴影、强景深或大范围 Bloom。

下一轮建议先制作一个覆盖两人正面、转头和近身动作的固定片段，比较“当前半兰伯特 + 新脸线”和“受控明暗/眼睛 + 发束与材质精修”。同动作同镜头 A/B 通过后再扩展全曲，保持旧预设可回退。[双人全曲配置与实际前置检查](DUET_FULL_PRODUCTION.md)记录了角色分配和已导入的现成相机。
