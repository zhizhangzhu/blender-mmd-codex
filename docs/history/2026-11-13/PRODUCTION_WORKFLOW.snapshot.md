# 从单角色试作到可复用 MMD 制作流程

## 视觉目标与证据

舞台氛围先在独立分支做无雾／有雾与基线的同姿态对照，再检查不同光向和运动。最新实测见 [半开放夜景](STAGE_ART_NIGHT_STUDY.md) 与 [鸣潮材质学习](WUWA_TOON_STUDY.md)。人物独立补光应呼应环境，Emission 型 NPR 表面不能假定自动响应场景灯；专用贴图先核通道、法线空间和 Alpha 设置，再考虑移植。教程语音与屏幕说明的获取边界见 [转写工具](TUTORIAL_TRANSCRIPTION.md)。

近期目标是向 Gosari542 的质量与渲染观感靠拢，再通过稳定试作发展自己的风格。指定参考为 [哥伦比娅 Pretty Girl【原神MMD】](https://www.bilibili.com/video/BV1nCWH6dEp9/)。2026-11-09 已通过 B 站公开 `x/web-interface/view?bvid=BV1nCWH6dEp9` 接口核实标题、作者及简介：模型署名观海 / miHoYo，动作八ツ橋まろん，舞台智沙都 / 37，Effects 为 Rui。

用户随后提供本地参考视频，已实际读取并抽取 8 个代表帧，1080×1920、约 60 fps、18.42 秒。具体画面观察与试样方向见 [GOSARI_REFERENCE.md](GOSARI_REFERENCE.md)。Effects 署名 Rui 是证据，但无法单独证明本片的具体 Ray-MMD 配置、灯光、采样数或作者工作软件。[Ray-MMD 作者仓库](https://github.com/ray-cast/ray-mmd) 明确该项目面向 MikuMikuDance；它可供研究渲染思路，不能作为 Blender 原生节点直接套用。

抽帧观察应记录时间码、光向、脸部明暗、发丝高光、眼睛、衣料、描边、背景模糊、背景亮度、色彩和构图。没有出现的景别不可虚构；镜头节奏、发丝物理及闪烁仍需连续播放验收。

用户后续增加观海子参考，并要求两类风格独立复用、横竖屏分别设计。制作前选择明确的风格/变体/画幅 package，记录渲染、后期、镜头与字幕布局；入口和已验证组合见 [STYLE_PRESETS.md](STYLE_PRESETS.md)。个人风格从保留的参考基线上另建版本，不覆盖原预设。

## 每轮制作顺序

1. **保留导入基线。** 独立后台进程、新输出目录，导入 PMX，再选择根 Empty 导入原生 VMD。保存输入路径、版本、缩放、fps、帧范围、贴图和骨骼/Morph 匹配报告。先确认身体真的在动，区分缺失的核心骨骼和原模型专有饰品骨骼。
2. **检查动作。** 先看片段预览，检查脚底、膝盖、手指、肩肘、嘴型、视线。按源说明比较脚 IK。帧数充足不等于动作正确；不能仅用「导入成功」验收。
3. **处理物理。** 副本中组装刚体，设置预滚，按时间顺序模拟，再缓存/烘焙。检查头发、裙摆、披肩的碰撞、抖动与穿模。未构建物理的草稿明确标注，禁止把随机跳帧结果当最终物理。
4. **做静帧材质试样。** 同一姿态、相机和灯光分别试 EEVEE 与所需的 Cycles 材质路线。先脸和眼睛，再头发、衣料、金属，最后描边/Glow。每次只调整一类，保存参数和对照图。纸片人助手的 Shader to RGB 路线优先在 EEVEE 验证。
5. **镜头与舞台。** 在动作稳定后制作近、中、全景及焦点；静态导入检查镜头只是基线。确认参考画幅后再决定正式横竖屏，不从本次竖屏预览推断目标视频画幅。
6. **短片验收。** 先出 5–10 秒预览，检查脚滑、穿模、阴影和高光闪烁、描边破裂、降噪拖影、嘴型和节拍。确认后再渲整段。
7. **正式输出。** 优先图像序列以便断点续渲，再合成音轨与视频。记录分辨率、fps、引擎、色彩管理、采样/阴影设置、合成节点及每帧耗时。片尾署名和素材使用范围随项目归档。

## 迭代里程碑与验收

| 阶段 | 交付 | 通过标准 |
| --- | --- | --- |
| P0 环境 | 环境 JSON、API 清单 | 实际加载正确插件，源素材保持完整 |
| P1 单角色导入 | blend、静帧、导入报告 | 贴图可读，骨骼动作存在，未匹配项可解释 |
| P2 动作/物理 | 5–10 秒低成本预览 | 身体、脚、表情及衣发运动无明显错误 |
| P3 风格 | 同镜头静帧 A/B 与参数 | 与指定参考逐项对照，用户选定方向 |
| P4 成片 | 图像序列、视频、署名 | 全片连续验收通过，可按记录重渲 |

当前仓库提供的 `scripts/mmd_first_scene.py` 是 P1 草稿生成器：不烘焙物理，不实现目标作者的材质，不生成最终相机。后续每个通过的试验再提炼成预设和工作指导，避免把临时参数当通用标准。

后续已加入从 P1 推进到成片的独立流程：原生衣发物理视觉烘焙、保留 PMX 语义的 NPR 材质、原创舞台、竖屏相机、60 fps 重定时和工程/视频验收，见 [PRODUCTION_TECHNIQUES.md](PRODUCTION_TECHNIQUES.md)。调用 `mmd-finish-render` 时按该流程交付完整所选片段的视频，不把早期导入草稿当作终点。
