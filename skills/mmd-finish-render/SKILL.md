# 从导入工程推进到成片

先读项目的已确认目标、素材版本、参考视频与当前产物。沿用用户选定的角色/动作，明确成片片段和技术规格；已有授权范围内持续推进到实际视频。音频来源、是否卡点、是否有人声分别记录，尊重用户留给自己处理的音频工作。

**物理与便携性。** 检查 PMX 刚体、关节、动态骨骼和源动作的 IK 说明。先在独立副本上验证少量帧，再做有预滚的连续模拟，不能以随机跳帧评估未缓存物理。优先复用模型原生物理；不适用时学习并验证替代方案。将结果视觉烘焙到骨骼 Action，在不同进程中重新打开验证，再移除实时物理和辅助物体。原生模拟、导出 Action 和清理后的工程之间抽样比对姿态，防止「烘焙成功」却丢失运动。

**参考驱动的美术。** 从实际参考帧确定构图、脸和眼睛、发丝、衣料、明暗、背景和景深。先做同姿态 A/B，确认细节与高光，再检查连续运动。MMD 材质包含透明、球面贴图和叠层，重建着色器前确认这些语义。本机验证了保留上游链后直接使用 MMDShaderDev 的 Color/Alpha 输出，按材质分区做 NPR 的路线，见 [LOOK_REFINEMENT.md](../../docs/LOOK_REFINEMENT.md)。旧工程 Shader to RGB 加逐通道压缩使颜色偏灰，不应默认复用。区分画面美术控制和真实光照，不能宣称还原了参考作者原始节点。

**相机与时序。** 单人/双人、横屏/竖屏镜头须适配，检查手部与头部构图及背景穿透；只验证头部点在框内不够。改变输出 fps 时同时变换关键点和左右插值柄的时间轴，验证同一实际时间姿态不变，不可只修改 fps 或伪装重复帧为新运动。

**字幕与灯光。** 用户要求稳定前后关系时，按实际动画分组固定层级；前景字幕不再按脸部遮罩局部挖开，背景字幕使用连续人物覆盖率。黑底 MP4 不是 RGBA，需区分字形内孔与白牌中的黑字。参照 [双人字幕与聚焦灯光](../../docs/DUET_CAPTION_STABILITY_AND_LIGHTING.md)，逐帧审计并检查切换处连续帧。灯光不明显时先确认场景材质是否响应真实灯光，再定位实际接收表面；不能仅在自发光 NPR 上叠灯后宣称氛围已改变。

**成片验收。** 保存可重渲的项目和参数，打包贴图；实际渲染完整所选片段并等待编码完成。逐帧解码检查帧数、尺寸、fps、时长、黑帧和冻结，抽帧做全片目视检查；检查音轨存在并能解码。技术检查不等于全部美术问题都已解决，不得夸大相似度或称为像素级复刻。交付成片、工程、来源署名和有效流程文档。

本机具体脚本、Blender 5.2 API 差异和实测参数见 [PRODUCTION_TECHNIQUES.md](../../docs/PRODUCTION_TECHNIQUES.md)。模型材质名和数值是阿克西妮娅的实例参数，不应盲用于其他角色。
