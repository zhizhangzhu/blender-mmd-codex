# MMD 故障排除

## 分析順序

1. 檢查 Blender 執行檔與版本。
2. 檢查 Add-on 是否載入。
3. 檢查輸入檔案、相對路徑與檔案權限。
4. 檢查模型、骨架、材質、貼圖與物理資料。
5. 讀取完整錯誤訊息與操作日誌。
6. 提供最小可重現步驟與可回復的修正方式。

## 安全要求

沿用使用者已給的授權，在作品副本或獨立場景中執行可逆診斷與修正。覆寫唯一原檔、刪除素材或超出授權的批次變更，先說明具體影響並確認；普通檢查與已授權腳本無需重複確認。

## 已觀察的工具差異

Blender MCP 1.19.0 的 `execute_blender_code` 會在腳本執行後整理資料變動。如果腳本刪除呼叫前已存在的物件，整理階段可能觸發 `StructRNA of type Object has been removed`，即使導入或渲染已經完成。先讀回場景和產物，避免直接重試造成重複模型。新作品可建立獨立 Scene 並保留既有物件；確實需要刪除時使用經驗證的其他操作路徑，或在獨立後台作品中執行並檢查結果。不要聲稱此錯誤已自動回滾全部變更。
