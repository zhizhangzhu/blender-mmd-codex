# VMD 工作流程

本机可用已安装的 MMD Tools 扩展执行 PMX/VMD 导入，详见 `../../docs/LOCAL_ENVIRONMENT.md`；`../../scripts/mmd_first_scene.py` 提供独立导入草稿流程。下述「未完成解析」指本仓库自有解析器，不代表不能调用外部插件。原生 VMD 优先使用日文 PMX 骨名映射；选模型根 Empty 才能同时导入骨骼与 Morph。输入是 FBX 时另走骨架检查和重定向，不套用 VMD 导入流程。

## 目前版本範圍

本技能先負責需求判斷、輸入檢查與 Blender 工作流程規劃。VMD 二進位解析、骨架名稱對應與重定向會在後續版本加入。

## 輸入優先順序

1. 原始 VMD／VPD／相機檔：可進行資料級套用。
2. PMX／PMD 與已存在的 Blender 場景：可進行模型與場景檢查。
3. 只有 MMD 渲染影片：先走 `mmd-video-reference`，不可當成 VMD 原始資料。

## 輸出要求

- 明確列出已成功讀取的輸入。
- 明確列出需要人工修正的骨骼、表情、相機與物理差異。
- 自有VMD解析器尚未完成不等于不能用已验证的MMD Tools导入；实际调用导入器并核对骨骼／Morph后，可以如实记录数据级套用。未实际导入、未检查映射时不得声称套用完成；导入通过仍不等于动作、物理或全片质量通过。
