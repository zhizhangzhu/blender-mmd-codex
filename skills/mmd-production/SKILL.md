# Blender MMD 制作

用已连接的 Blender MCP 操作场景，用 MMD Tools 处理 MMD 格式。接到制作需求后推进到可检查的 `.blend`、预览或视频，按用户要求的完成范围交付。

## 接入与任务定位

- 先识别用户给的是 PMX/PMD 模型、人物/表情/相机 VMD、VPD、`.blend`、音频，还是渲染后的参考视频。MP4 不能代替原始动作文件。
- 沿用已明确的角色、歌曲、画面风格、时长和输出要求。缺少素材时先检索，无法合理推断的创作选择再询问。
- 用实际可用的 MCP 工具发现 Blender 实例。多个实例时根据文件/场景精确匹配；选不出来才让用户指定。先读取场景和版本，再修改。
- 如果当前会话没有 Blender MCP 工具，说明需要重新载入客户端工具；可以准备素材、脚本或用 Blender 后台处理新的独立文件，但不要声称已经改了用户打开的场景。

## 按任务读取参考

- 找模型、动作和镜头：使用同级 [mmd-asset-search](../mmd-asset-search/SKILL.md)，再读 [资源目录整理](references/asset-research.md)；该检索技能也可独立调用。
- 导入模型/动作/相机、改镜头、检查物理：读 [Blender 操作](references/blender-operations.md)。
- 预览、正式渲染、音频同步和视频输出：读 [渲染与输出](references/render-output.md)。
- 学习新教程或处理版本差异：读 [学习来源与更新](references/learning-sources.md)。

## 制作过程

1. 为当前作品保留来源记录和独立工作目录，保留模型贴图的相对路径。新作品从独立场景开始，修改旧作品先保存新版本。
2. 通过 MMD Tools 导入模型、人物动作和相机动作；记录统一的导入比例、起始帧、帧率和目标对象。每次导入都回读实际对象、动作或关键帧，避免将 `FINISHED` 当作完整套用。
3. 按需求设置舞台、材质、灯光与镜头。一次调整一个可判断的目标；查看相机画面和时间段内的实际运动。物理问题先检查比例、预热和碰撞，再局部调整。
4. 在开头、运动/转身明显处、接触处、切镜和结尾查看画面，渲染有代表性的短片。根据预览修正贴图、构图、脚滑、穿模和头发/裙摆问题。
5. 保存检查点后渲染完整帧序列，再合成视频和用户提供的音频。跟进到进程结束、产物存在且可解码；用播放或代表帧评估视觉结果。

## 交付

报告 `.blend`、预览/视频和来源记录的位置，说明分辨率、帧率、时长、已完成的操作以及仍看得见的问题。明确区分环境验证、合成测试素材验证、真实素材验证与视觉验收。下载失败、配布关闭或缺少必要许可时保留候选页和原因，继续可完成的制作准备。
