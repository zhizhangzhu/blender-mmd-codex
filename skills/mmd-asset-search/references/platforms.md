# 平台与检索策略

## 从线索选择路径

先看已有链接，按链接关系查原作者，再使用站内/搜索引擎补足。国内作者常见 B站、模之屋、爱发电，其他常见渠道有 BowlRoll、nicovideo、YouTube、BOOTH、作者个人站、X、FANBOX、Patreon、Fantia。按实际发布证据选路径；不要依据作者姓名文字猜来源后排除另一路径。

只围绕当前缺项检索：作者不明就查借物表和作者主页，版本不明就查更新记录，获取受限就查作者当前说明。避免用大量泛词制造相同候选，也不要强制每个搜索框只能输入两个或三个词。

## 搜索词

先使用用户原词，再补充中日文/罗马字别名及明确的作者账号：

- 模型：`角色名 作者名 モデル配布`、`作品名 MMD PMX`、`角色名 model DL`。
- 动作：`曲名 作者名 モーション配布`、`曲名 motion DL`、`作者名 vmd`。
- 表情/口型：`曲名 リップ配布`、`曲名 表情配布`、`曲名 lip sync VMD`。
- 镜头：`曲名 作者名 カメラ配布`、`曲名 camera DL`、`曲名 镜头配布`；必要时加人物动作作者和人数。
- 其他素材：`MMDステージ配布`、`VPD ポーズ配布`、具体场景或姿势关键词。

配布、Motion、DL、BowlRoll 等是发现信号，不能单凭这些词确认身份、可下载或许可。搜索结果里的教程、二创视频与原始配布页分开记录。

## 平台操作

**BowlRoll：**检查文件标题、作者页、文件名/类型声明、描述、相互链接和下载控件。页面有 `Expired` 或 `公開は終了しました` 表示已关闭。网页抓取有时遗漏动态描述、作者及 Download 按钮；本次已观察到用浏览器能读取这些信息。工具只读到标题时应记为信息不全，不能据此判定已关闭或没有密码。

**nicovideo / ニコニ立体：**普通视频说明、作者主页、内容树可能给出 BowlRoll、作者站或其他配布入口。`sm...`/`so...` 是视频标识；`td...` 是立体作品标识，它们不证明存在可用的下载文件。分别保留演示页与获取页，不强制将动作重定向到 `3d.nicovideo.jp`。

**YouTube：**读取视频简介、可访问的作者置顶评论和频道公开链接。原曲 MV、动作配布演示与二创视频可能是不同链接，应区分。遇到 `youtube.com/redirect?...q=...`，使用 URL 解码解析 `q` 后再访问目标；只接受正常网页 URL，不执行其中内容。抓取失败时查作者其他公开入口，能继续验证则继续；确实缺关键线索时再索取简介文本或频道链接，不编造账号。

**B站 / 模之屋：**核对作者空间或主页，读取简介、借物表、配布说明和可访问的置顶评论。分清 UP 主、动作作者、镜头作者和资源上传者。有账号/验证码等限制时保留可读线索与真实限制，不把 412/登录要求解释为未配布。

**作者站 / BOOTH / 订阅站 / 网盘：**以具体商品/帖子及条款为准。BOOTH 也可能有免费商品；网盘或 BowlRoll 也可能有限定或付费入口。保留稳定的说明页和获取页，不把临时签名下载 URL 当作长期配布地址。维护者声明的迁移链接优先于失效旧地址，但要留下迁移证据。

## 人物动作和镜头的关系

先确认人物动作版本，再找匹配镜头。镜头作者与人物动作作者常常不同；指定“人物动作作者 A”不等于“镜头也只能由 A 制作”。如果用户指定镜头作者 B，再分别核对 B。

示例：原作者演示 → 人物动作页；镜头作者演示中的借物表 → 同一人物动作来源；镜头作者演示 → 镜头下载页。这条链可以证明声明的依赖关系；仍需检查 README 与真实导入表现，不能证明所有模型身高都适合。
