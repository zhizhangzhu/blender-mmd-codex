# 结果记录与获取规则

## 状态分开写

不要用一个“成功”覆盖所有阶段：

- **身份/来源：**作者关系已核实 / 作者自称但未交叉核实 / 待核对 / 作者不匹配。
- **页面：**实际打开 / 仅搜索摘要或缓存 / 登录或验证限制 / 失效或配布終了。
- **获取条件：**公开免费 / 付费商品 / 订阅；另列密码、登录、关注、点赞、需联系或群配等条件。密码本身不必然表示付费或限定；不能因需要私信或加群就断言不是正规配布。
- **文件：**未下载 / 已下载及哈希 / 已解压并检查 README / 已导入指定 Blender 与插件版本。
- **兼容性：**已确认依赖的动作版本 / 依赖未知 / 存在人数或帧率等差异 / 已在指定模型上检查。

“仅展示视频”只能在有证据确认无配布时使用；只因当前工具没找到链接，应写“已找到作者展示，尚未定位配布入口”。文件未读取时，密码与许可写“页面未说明/尚未核实”，不推定付费包无密码或公开包可商用。

## 可保存的来源记录

实际制作时在作品 `sources` 目录记录：

- 资源名称、类别、角色/曲名、作者、发布账号、各角色署名和版本。
- 原始说明/配布演示/获取页 URL，作者交叉链接或授权说明的证据。
- 获取条件、价格和核对日期、公开密码或提示的来源（作者要求不公开时仅链接说明）。
- 使用条款链接、当前用途相关限制、署名要求，未确认项。
- 镜头依赖的人物动作作者/版本、人数、帧率、起始帧、时长和身高信息。
- 实际核对时间、页面状态；下载后追加本地路径、SHA-256、包内 README 与导入结果。

字段未知就写未知，允许结果不完整。不要将用户凭证、私密下载 token、群文件或付费内容纳入公开报告或 Git。

## 公开文件下载

只有当前用户任务已涵盖获取素材才下载；阅读/评估一个 Skill 本身不授权下载它提到的任何素材。使用作者明确给出的公开入口和公开密码/提示。不尝试猜密码或批量试错；登录、付费、关注者限定或已关闭资源保留状态，由用户完成需要其参与的步骤。不要联系作者、自动加群、发私信、订阅或下单。

下载后保留原压缩包、作者说明和内部目录结构，单独解压，检查不安全的绝对路径与上级跳转，不执行包内脚本或程序。按实际文件扩展名/结构识别人物、口型、镜头轨道；第三方素材和实际作品放到用户选择的素材目录或项目已忽略的 `mmd_projects/`，不提交代码仓库。

没有读取 README 就不宣称使用条款已核实；看到下载按钮也不宣称下载成功。读取条款、展示候选和技术导入验证均不自动证明用户拥有商业使用或再配布许可。
