# MMD 素材检索

使用现有搜索、网页读取和必要的浏览器工具寻找 PMX/PMD、VMD/VPD 配布。此技能提供检索与核对流程，无额外 API 或程序依赖；网页不可读时能力会受当前工具、登录状态和站点限制影响。

## 确定目标

- 识别要找的是模型、人物全身动作、表情/口型、相机轨迹，还是整套素材。VMD 扩展名相同不表示轨道用途相同。
- 接受视频链接、角色/作品名、曲名、动作或镜头作者中的现有线索，不强制每次都提供曲名和作者。用户指定作者时，该作者的版本是硬条件；未指定时可以比较不同作者。
- 用户给视频时先读标题、简介、借物表和可读的作者置顶评论，分别提取音乐、编舞、动作、镜头、模型及发布者。借物表中的音乐作者不自动等于动作作者。
- 找“下一个”时清空上一资源的曲名、作者、候选和结论；保留作品用途、许可要求、预算、语言偏好及已授权范围。不要将上一作者套用到新目标。

## 检索与核对

1. 先追踪用户给出的直接链接和原作者公开的配布链接。已有明确入口就验证它，不强制再走完所有平台。
2. 根据原作者实际活动渠道选择站点。常见入口和搜索词见 [平台与检索策略](references/platforms.md)。文字姓名不能证明国籍、作者身份或发布平台。
3. 优先从作者主页、视频/公告中的链接核对发布者。作者跨平台别名、机构代理、获授权维护者或作者迁移的配布地址可以成立，需要原作者交叉链接、明确声明或文件署名等证据。上传账号文字不同既不能直接排除，也不能自动认定同一人；未经证实的第三方重传不能升级为作者配布。
4. 动作、作者、音乐、配布四类线索中两个相关，可作为宽松候选线索；这不是正确版本或可用下载的证明。打开页面核对版本、作者关系与获取状态后再给结论。指定作者不匹配的版本不得作为满足请求的结果。
5. 网页读取只返回标题、文件大小或通用导航时，视为信息不完整。优先用已提供的作者链接和浏览器查看动态页面；可访问的普通 nicovideo 视频或 YouTube 视频简介也可能直接给出 BowlRoll/网盘等入口。`3d.nicovideo.jp` 是入口之一，不是唯一最终下载点。
6. 分别记录“来源是否确认”“获取条件”“当前网页状态”“文件是否已验证”。有 Download 按钮只证明页面提供入口；搜索缓存与动态页面矛盾时以实际页面为主，并记录不确定性。`Expired`、删除、配布終了不能报告成可下载。
7. 除非用户明确要求穷举，找到足够匹配且来源可靠的结果即可交付。连续几轮搜索没有新线索时，报告查过的渠道与具体缺项；页面不可读不等于资源不存在。缺少关键身份信息才请用户补充。

## 按资源类型补充

| 类型 | 必须核对的差异 |
| --- | --- |
| 模型 | 角色/作者/模型版本、PMX/PMD 或其他格式、贴图与骨骼要求、角色和模型条款；未下载时格式及内容写明依据是页面声明 |
| 人物动作 | 曲名/动作作者/版本、单人或多人、全身/口型/表情、特殊骨骼、预热或偏移、配套说明；音乐和编舞署名单独保存 |
| 镜头 | 镜头作者与版本、所依赖人物动作作者/版本、人数、帧率/起始帧/时长及模型身高；未知项保留未知，不能仅凭同曲名认定兼容 |

## 获取与交付

读取 [结果记录与获取规则](references/results.md)。保留作者配布说明页、配布演示、最终获取页和相互关系；免费/付费与密码/登录/关注/群配等条件分别记录。公开列出的密码或官方解题提示需附来源；不猜测密码、不绕过关闭配布、付费或访问控制。

按用户已授权的范围推进。购买、订阅、入群、私信或获取未公开文件不因技能触发而自动获授权。正常公开文件下载若属于当前任务可继续；下载后检查文件类型、包内 README、哈希和依赖，再移交制作流程。未实际下载/解压/导入就不报告这些步骤已完成。

默认输出简短候选表和必要差异，不设置会截断证据的 100 字上限。存在多个官方获取方式时按用户的免费/付费偏好筛选；用户未表态则中立列出。保留已关闭但重要的指定版本线索，明确不可用状态，避免偷偷换作者。

本文根据用户提供的动作检索 v4.1 流程适配并扩展。规则调整与实证边界见 [适配说明](references/source-notes.md)。
