# MMD 參考影片工作流程

## 重要定義

使用者提供的 MMD 影片通常是已渲染的 2D 影片，不等於原始 VMD、相機或物理資料。影片可以作為視覺參考，但不能直接還原原作者的所有骨骼旋轉與物理設定。

## 工作流程

1. 確認影片檔案存在，記錄格式、影格率、解析度與長度。
2. 將影片加入 Blender Video Sequence Editor，從第 1 格開始作為參考。
3. 將目標 PMX／PMD 模型放在可比較的場景中。
4. 先提供影片對照工作流程；只有使用者要求時才進行姿勢擷取或骨架重定向。
5. 若只取得影片，將輸出標記為「近似動作」；若取得原始 VMD／相機檔，才可進行資料級套用。
6. 匯出前檢查穿模、腳底滑動、手指、表情、鏡頭與物理差異。

## 結果分級

- 影片參考：將影片放入時間軸，供人工對照。
- 動作近似：從影像取得姿勢並產生可修正的關鍵幀。
- 原始資料套用：使用 VMD、VPD、相機或 Blender 專案等原始資料。

不得宣稱只有 MP4／MOV 時可以百分之百還原原始 MMD 動畫。
