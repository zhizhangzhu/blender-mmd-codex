# 镜头 VMD 检索与验收

先确认曲名、本家/动作作者、实际使用的 VMD 文件，以及 Full/Short/Solo 和人物分轨。作者未指定时可查不同镜头作者；不能把不同编舞的同名曲镜头混作适配结果。优先查官方配布清单，再查第三方作者的演示简介、作者主页和配布页。

检索词可组合曲名与 `カメラ配布`、`Camera DL`、`カメラモーション`、`1人用`、`ソロ`、`フル`；BowlRoll、YouTube、Niconico、B 站都可作为线索。搜索摘要和聚合站仅供定位，最终回到作者原页核对。YouTube redirect 需解析真实外链；页面暂时不可读不等于没有配布。

对每个候选记录：镜头作者、演示、配布页、支持的动作/版本、人数与身高说明、密码获取说明、授权和当前验证状态。密码按作者指定方式获取和使用；作者要求不传播时只给获取页面，不转贴密码。登录、关注或付费要求不能靠猜测绕过。

无需密码且公开的 BowlRoll 小镜头 ZIP 可使用仓库 `scripts/bowlroll_public_download.py`；它只执行站点普通匿名下载流程。其他情况使用作者正常配布入口。下载后先读 readme，保留原包与来源，不执行包内代码；改造镜头的再配布限制同样适用于上传仓库。

先解析确认 VMD 有相机关键帧，记录帧范围和缩放。用 `scripts/mmd_camera_check.py` 在原项目副本中导入，检查人物动作未被覆盖，再检查不同时间点的构图、切镜插值、近裁剪和背景穿透。单人动作与双人镜头、横屏镜头与竖屏画幅都必须实际复查。该脚本可对指定片段生成独立的单人构图跟随偏移，但这不等于完整美术运镜。头部坐标在画面内仍可能只有肩膀大特写，需结合实际帧图检查景别；近景限制应按模型尺寸与镜头意图设置。

区分「找到作者配布」「已下载/读说明」「Blender 导入通过」「单人构图通过」「动态预览通过」。不能把一个状态当成后面的状态。找不到合适配布时可另行制作镜头并明确来源，不能伪称原作镜头。

本项目的已核实候选和示例命令见 [镜头检索记录](../../docs/CAMERA_SEARCH.md)。需要找原曲或伴奏时读其中的素材来源段；音频对齐按用户当前要求执行，不因发现配套音频就自动认为已卡点。
